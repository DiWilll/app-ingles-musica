Quero o player dentro do app (sem Python)

O player só funciona quando a página é aberta por http:// ou https://. Algumas opções que não precisam de Python:

  1. Hospedar grátis: publicar o arquivo no GitHub Pages, Netlify ou Cloudflare Pages. Deves renomeá-lo para index.html.
  2. VS Code: com a extensão Live Server, clica com o botão direito no arquivo e escolhe "Open with Live Server".
  3. Node.js: se o tiveres instalado, executa npx serve na pasta do arquivo.
